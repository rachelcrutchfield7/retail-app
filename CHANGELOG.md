# Changelog

## 1.0.0-beta

- Added persistent Supabase-backed marketplace flows.
- Added rescue accounts, Rescue Hub, urgent needs, and wishlists.
- Added realtime messaging, unread counts, blocking, and reporting.
- Added transaction completion, reviews, profile ratings, notification center, notification preferences, and account deletion support.
- Added beta hardening guardrails: pinned dependencies, CI workflow, environment template, release docs, error boundary, offline banner, and QA checklist.

## Known Beta Limitations

- OS-level push notification delivery is not fully enabled.
- Production Stripe payments remain gated.
- EAS preview builds still need to be run and verified on physical devices.
